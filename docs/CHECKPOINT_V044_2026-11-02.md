## Correção mínima

Alterado **somente** `src/styles.css`: piso tipográfico de **10 CSS px** nos grupos informativos acima, sem alterar rótulos nem reduzir títulos; resguardadas as fontes maiores já existentes no desktop para rótulos de métricas. A cor do código de atividade saiu de cinza claro para cinza-azulado mais legível (`#59627d`). Em 280px o aviso de dados fictícios passa a **duas linhas**, e o rodapé cresce para **78px**, com `max-width` calculado para não atravessar o emblema Academy nem o botão Menu. As demais larguras mantêm rodapé normal. Sem CSS `overflow-x:hidden`, sem novos pacotes, sem alterações no TypeScript/dados/API/permissões/regras. Isso é um ajuste de legibilidade, não mudança livre de identidade visual.

**Importante:** 10px é uma **meta de legibilidade interna** para metadados críticos, **não** um mínimo normativo de WCAG 2.2 AA. Não declarar conformidade por esse número.
